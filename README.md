#  Astro Pi: Mission Zero (2024–2025)

This is the code written by **Georgios** and **Nikolaos** (**Team `nickgeo`**) from **Griechisches Gymnasium - Lyzeum Bielefeld** for the European Astro Pi Challenge: **Mission Zero (2024–2025)**.

Astro Pi is an educational project run by the **Raspberry Pi Foundation** in collaboration with the **European Space Agency (ESA)**, giving students the opportunity to write Python code that runs on Raspberry Pi computers aboard the International Space Station (ISS).

##  ISS Flight Details

Our program achieved flight status and was executed aboard the International Space Station!

* **School:** Griechisches Gymnasium - Lyzeum Bielefeld
* **Execution Date & Time (UTC):** `2025-05-16` from `19:09:15` to `19:10:15`
* **ISS Coordinates:** `-0.6871, -60.0409` *(Over the Amazon Rainforest in northern Brazil, near Manaus)*

##  What the Code Does

*That year ESA had put many limitations but also very few requirements for the code that would run on space compared to the previous year. That year we only had to show a specific pixel-art image we had made whereas in the previous years we sent a message to the astronauts and pulled data such as temperature, humidity and color*
